# Roll for English

What you will find here are the materials needed to create an English learning
board game for groups of English as a Second Language (ESL) students.

_The game has not been beta tested yet! Use at your own risk._

If you want to get started right away, download Materials.pdf and print it on
US letter paper with a color printer. Write in you own learning objectives
in the 42 path spaces, find a pair of six-sided dice, and go adventuring.

If you want to customize things:

1. Use LibreOffice Draw to edit Materials.odg.
2. Use The GIMP to edit Map.png.
3. Save your custom PDF and share with your class.
